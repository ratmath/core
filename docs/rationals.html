Rationals

A Rational is a fraction p/qp/qp/q held as two BigInts, always in lowest terms with q>0q > 0q>0. Sums, products and quotients of fractions are fractions, so nothing is ever rounded.

Lowest terms

Every constructor divides out g=gcd⁡(p,q)g = \gcd(p, q)g=gcd(p,q) and moves the sign to the numerator, so two equal values always have the same parts and equals is a comparison of two pairs of integers. Arithmetic uses the schoolbook rules and reduces again:

ab+cd=ad+bcbd,ab⋅cd=acbd,ab÷cd=adbc. \frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}, \qquad \frac{a}{b}\cdot\frac{c}{d} = \frac{ac}{bd}, \qquad \frac{a}{b} \div \frac{c}{d} = \frac{ad}{bc}. ba​+dc​=bdad+bc​,ba​⋅dc​=bdac​,ba​÷dc​=bcad​. 
import { Rational } from "@ratmath/core";

new Rational(6, -8).toString();            // "-3/4"
new Rational("2..1/3").toString();         // "7/3" (mixed number)
new Rational("0.#3").toString();           // "1/3" (repeating decimal)
const x = new Rational(2, 3);
x.add(new Rational(5, 6)).toString();      // "3/2"
x.pow(-2).toString();                      // "9/4"
x.E(3).toString();                         // "2000/3", times 10^3
x.lessThan(new Rational(3, 4));            // true

A string argument may be any number literal (integer, fraction, mixed number, decimal, repeating decimal); a second argument divides it, so new Rational("3/4", 5) is 320\tfrac{3}{20}203​. Number arguments must be safe integers.

Repeating decimals

Every fraction has a decimal expansion that ends or repeats forever. RatMath writes the repeating block after a #: 16=0.16‾\tfrac16 = 0.1\overline{6}61​=0.16 is 0.1#6, and 17\tfrac1771​ is 0.#142857. Both directions are exact: parseDecimal("0.1#6") gives back 16\tfrac1661​.

Why it repeats: long division of ppp by qqq only ever has remainders 0,1,…,q−10, 1, \ldots, q-10,1,…,q−1, so within qqq steps a remainder comes back and the digits cycle from there. Write q=2a5bmq = 2^a 5^b mq=2a5bm with gcd⁡(m,10)=1\gcd(m, 10) = 1gcd(m,10)=1. Then the expansion has max⁡(a,b)\max(a, b)max(a,b) digits before the period, and the period length is the order of 10 modulo mmm: the least kkk with

10k≡1(modm). 10^k \equiv 1 \pmod m. 10k≡1(modm).

The decimal ends exactly when m=1m = 1m=1. For 17\tfrac1771​, 106=142857⋅7+110^6 = 142857 \cdot 7 + 1106=142857⋅7+1, so the period is 6. Going back is a geometric series: a block BBB of kkk digits repeating forever is B/(10k−1)B/(10^k - 1)B/(10k−1), which is why 0.#9 is exactly 1.

const sixth = new Rational(1, 6);
sixth.toRepeatingDecimal();                // "0.1#6"
sixth.toRepeatingDecimalWithPeriod();      // { decimal: "0.1#6", period: 1, truncated: false }
new Rational(1, 97).toRepeatingDecimal(100);   // 96-digit period, limit raised to 100
new Rational(1, 97).toRepeatingDecimal(10, "trunc");   // "0.#0103092783..." (display only)

The default period limit is 30 digits (Rational.MAX_PERIOD_DIGITS). Past it, toRepeatingDecimal throws unless you pass a larger limit, or "trunc" for a display string ending in ..., which is deliberately not parseable. computeDecimalMetadata() returns the pieces (whole part, pre-period, period digits and length) for your own formatting.

Rounding

floor, ceil, trunc and round(mode) return bigints; roundTo(places, mode) returns a Rational with at most that many decimal places. Modes are half-even (the default, banker's rounding), half-up, toward-zero, floor and ceil. Because the value is exact, the rounding is decided correctly even for ties like 2.52.52.5 that floats cannot always see.

const t = new Rational(5, 2);
[t.floor(), t.ceil(), t.round(), t.round("half-up")];   // [2n, 3n, 2n, 3n]
new Rational(2, 3).roundTo(3).toString();               // "667/1000"
