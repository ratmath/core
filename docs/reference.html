Reference

Everything in the library

Every item below is a named export of @ratmath/core; the default export is an object holding the same values. Inputs written q accept a safe integer number, a bigint, a string such as "3/4", "0.#3" or "1..1/2", or a Core value. That applies to constructors and helper functions; the arithmetic methods (add, multiply, …) take Core values, so write half.add(new Rational(1)) or R`1/2 + 1`, not half.add(1). Operations never return NaN or infinity: division by zero, 0^0, an interval divisor containing 0 and malformed text throw an Error. The shipped index.d.ts has the exact TypeScript signatures.

Fast first, exact last

A separate entry point, @ratmath/core/refine, holds the two-step answer shared by linalg, analytic and graphics: a float preview at once, the exact answer after.
