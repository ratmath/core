Chains and regions

Three or more values joined by colons are a betweenness test: R`0:${x}:1` is true when \(0 \le x \le 1\). Since 0.9.0 a chain can have strict links (:!), open ends (_) and alternatives (||), and Region reads the same text as a set.

Betweenness

A chain holds when its values run in one direction, ascending or descending, with ties allowed. An interval operand counts with both its ends, so 0:(1/4:1/2):1 asks that the whole interval lie inside \([0, 1]\).

import { R } from "@ratmath/core";

const x = R`1/3`;
R`0:${x}:1`;           // true:  0 ≤ x ≤ 1
R`1:3:2`;              // false: 3 is not between 1 and 2
R`3:2:1`;              // true:  descending counts too
R`0:(1/4:1/2):1`;      // true:  both ends of the interval are inside

A chain is a test, not a number: R`(1:2:3) + 1` throws a TypeError. In TypeScript, use R.between`…`, which is typed as boolean and throws if its text is not a chain.

Strict links, open ends, unions

chainmeans
2:!x:8\(2 < x \le 8\): :! forbids a tie across that link
2:x:!8\(2 \le x < 8\)
_:x:8\(x \le 8\): _ beside a colon is an unbounded end
2:x:_\(x \ge 2\)
_:x:!-1 || 1:!x:_\(x < -1\) or \(x > 1\): || joins chains

A chain with _ always reads ascending (otherwise _:x:8 would hold for every \(x\)). _ anywhere else throws, as do two-value forms such as _:5 or 2:!5, which have no middle value to test.

const x = R`5`;
R`2:!${x}:8`;                   // true
R`_:${x}:!5`;                   // false: x < 5 fails
R`_:${x}:!-1 || 1:!${x}:_`;     // true

Regions: chains as sets

R.region and Region.parse read a chain on a named variable as a set of rationals, without a value for it. One other name in the bounds may be an integer variable, provided each bound is affine in it (like \(2n\) or \(3(n - 1)\)); the region is then the union over all integers \(n\):

\[ \texttt{2n:x:!2n+1} \;=\; \bigcup_{n \in \mathbb Z}\, [2n,\ 2n+1) \;=\; \cdots \cup [-2, -1) \cup [0, 1) \cup [2, 3) \cup \cdots \] 
import { R, Region } from "@ratmath/core";

const even = R.region`2n:x:!2n+1`;   // 2n ≤ x < 2n+1 for some integer n
even.contains(R`1/2`);              // true
even.match(R`5/2`);                 // { n: 1 }: which n put it there
even.within(0, 3).toString();       // "[0,1) U [2,3)"
even.breakpoints(0, 3);             // [0, 1, 2, 3]
Region.parse("a:x:b", { params: { a: 1, b: "5/2" } }).contains(R`2`);   // true

intervals(lo, hi) lists the pieces in a window, each { lo, hi, loStrict, hiStrict, n } (null for an unbounded end), and within(lo, hi) returns them as a RationalIntervalSet. Bounds may use + - * /, integer powers, parentheses and juxtaposition (2n). A region reads each chain ascending (lo:x:hi), so 8:x:2 is empty, unlike a plain R chain. A coefficient written next to the integer variable binds tighter than /: 1/2n means \(1/(2n)\), which is not affine and is refused; write n/2 for half of \(n\). This is what @ratmath/analytic uses for piecewise functions like x^2 if 0:x:!1; 1 otherwise.
