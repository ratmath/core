Exact arithmetic, free-form

Type anything the R template reads and press Enter. Each answer shows its type and, under every form, the ways Core can write it: fraction, mixed number, repeating decimal, continued fraction, interval forms. Name a value with a = 1/7 and use a later; ans is the last answer. The base menu reads unprefixed literals in another base (R.base) and adds that base's expansion to the forms.
