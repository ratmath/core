Units and quantities

@ratmath/core/units attaches units to exact numbers. Every conversion factor is an exact rational (times a power of \(\pi\) for angles), so a mile is exactly 1609.344 metres and nothing is rounded until you ask for digits.

import { Q, units, constants } from "@ratmath/core/units";

Q("9.8 m/s^2").multiply(Q(3, "kg")).to("N");   // 147/5 N
Q(1, "mi").to("km");                            // 25146/15625 km
Q("20 degC").to("degF");                        // 68 degF
Q(2, "m").divide(Q(4, "cm"));                   // 50, a plain number

Quantities

Q(value, unit) or Q("value unit") makes a Quantity. The value is anything Core reads exactly: a Core number, a bigint, a safe integer, or a literal string such as "9.8", "1/3", "0.#3" or "1.2[3:6]". A JavaScript float like 9.8 is refused, as in R, because it is not the number you typed.

The quantity keeps its value in the unit it was written in. to(unit) converts, valueIn(unit) gives just the number, toBase() writes it in coherent SI base units and simplify() picks a named coherent unit when there is one (3/2 J/s becomes 3/2 W).

add and subtract need the same dimensions and answer in the left unit. multiply, divide, inverse and pow combine units; when the dimensions cancel the result is a plain number.

\[ \frac{5\ \text{km}}{2\ \text{h}} = \frac{5000\ \text{m}}{7200\ \text{s}} = \frac{25}{36}\ \text{m/s}. \]

Unit expressions

units.parse reads products, quotients and integer powers: "kg*m^2/s^2", "N m" (a space multiplies), "m/(s*kg)", "m·s⁻²", "1/s". Division is left to right, so "m/s*kg" is \(\text{m}\cdot\text{kg}/\text{s}\); units print with parentheses whenever a denominator has more than one factor, so printed units always parse back. toString({ style: "unicode" }) prints kg·m²/s².

SI prefixes work on the units that take them (km, mL, µs or us, kWh, mAh, MeV, also spelled out as kilometre), and binary prefixes on bits and bytes (KiB, MiB). An exact name always wins, so min is a minute and pt a pint.

Dimensions

The base dimensions are Mass, Length, Time, Current, Temperature, Amount, Luminosity, Angle and Information, with coherent units kg, m, s, A, K, mol, cd, rad and bit. Angle counts as a dimension so that degrees cannot be added to metres; Information so that bytes cannot be added to seconds. Adding, subtracting, comparing or converting across dimensions throws and names both dimensions.

Angles and \(\pi\)

A unit's size is \(s\cdot\pi^k\) base units with \(s\) rational and \(k\) an integer. A degree is \(\tfrac{1}{180}\pi\) rad, a turn \(2\pi\) rad, a parsec \(\tfrac{648000}{\pi}\) au. Conversions between units with the same power of \(\pi\) stay rational: 90 degrees is exactly a quarter turn. Converting radians to degrees needs \(\pi\) itself, and then the answer is an exact interval that contains the true value, good to about 33 digits.

\[ 1\ \text{rad} = \frac{180}{\pi}\ ^\circ \in [57.2957795130823208767981548141051702,\ 57.2957795130823208767981548141051704]. \]

Temperatures

Celsius and Fahrenheit readings are points on a scale with a shifted zero, so they follow different rules from other quantities:

  • degC and degF are points. Converting between them, or to K, applies the offset: Q("20 degC").to("degF") is 68 degF.
  • Point minus point is a difference: Q("20 degC").subtract(Q("50 degF")) is 10 deltaDegC. Point plus difference is a point. Point plus point throws.
  • deltaK, deltaDegC and deltaDegF are differences and cannot be read as points.
  • K is absolute, so it works either way: Q("300 K").to("degC") is 26.85 °C.
  • Multiplying, dividing or raising a degC or degF value throws; convert to K first.

Intervals

An interval magnitude converts by the same exact factor, so it gets no wider: Q("1.2[3:6] m").to("cm") is 123:126 cm. relation(other) returns the Relation mask of possible orderings, compare returns −1, 0 or 1 and throws when overlapping intervals leave the order undecided, and equals is true only when the two are certainly equal.

Constants

constants holds the exact SI defining constants c, h, e, kB and NA, the gas constant R (their product kB·NA, so also exact), standard gravity g0, and the measured G as an interval of its CODATA 2018 value plus or minus one standard uncertainty.

Your own units

units.extend() copies the standard catalogue so you can add to it without changing it for anyone else. define(name, definition, options) takes a string such as "201.168 m", a Quantity, a Unit or a raw { dimensions, scale, piPower }, with optional aliases, prefixes: "SI" and a group. groups() lists named units by group, for a unit menu. register(key, unit) makes an existing Unit reachable under another key while keeping the same object, so a host can build a catalogue from units it already holds; prefixes follow the unit's own prefixes field.

extend({ scalars }) swaps the arithmetic on magnitudes. The RiX language uses this to pass its exact symbolic \(\pi\) and algebraic numbers, so in RiX a radian-to-degree conversion stays exact.

const mine = units.extend();
mine.define("furlong", "201.168 m", { aliases: ["furlongs"] });
mine.define("fortnight", "14 day");
mine.quantity("1 furlong/fortnight").to("mm/h");   // 4191/7 mm/h, exactly
